# Terra Santa · Casa 1 · Pacote de assets

Este pacote reúne os arquivos para gerar o vídeo no Higgsfield e continuar o modelo no Blender.

As imagens panorâmicas da pasta `01_PLAN` e `02_GENERATED` foram ajustadas para proporção 2,499:1, abaixo do limite 2,5 do Higgsfield. As versões originais foram preservadas com o sufixo `_source`.

## Ordem de uso

1. `01_PLAN/casa1_plan_original.png` — planta recebida, fonte geométrica.
2. `01_PLAN/casa1_plan_line_art.png` — planta estilizada para o primeiro frame.
3. `02_GENERATED/casa1_isometric_cutaway.png` — referência de massa 3D.
4. `02_GENERATED/casa1_social_interior.png` — referência da área social.
5. `02_GENERATED/casa1_private_wing.png` — referência do setor íntimo.
6. `05_HIGGSFIELD/higgsfield-casa1-prompt.json` — prompt estruturado.

## Blender

`04_BLENDER/casa1_terra_santa.blend` é a cena editável gerada.
`04_BLENDER/casa1_scene.py` é o script regenerável.

O modelo é um estudo conceitual. A planta não deve ser tratada como documento executivo ou como escala confirmada.
