# Casa 1 · Terra Santa · Blender

The scene is generated procedurally from `casa1_scene.py`. It keeps the received plan as a replaceable reference and builds a conceptual, non-certified study model with named collections for structure, openings, interiors, garden, and cameras.

Run from Blender 4.x:

```text
blender --background --python blender/casa1_scene.py
```

The script saves `blender/casa1_terra_santa.blend` and renders a hero preview to `blender/renders/casa1-hero.png`.
