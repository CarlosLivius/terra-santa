# Terra Santa — Pacote Spec-Driven

Este diretório contém a especificação executável do protótipo mobile interativo da Terra Santa.

## Ordem de uso

1. Leia `01-product-spec.md` para compreender produto, escopo e critérios de aceite.
2. Leia `02-experience-spec.md` para implementar a experiência, animações e linguagem visual.
3. Leia `03-technical-spec.md` para definir arquitetura, dados, desempenho e acessibilidade.
4. Execute `04-implementation-tasks.md` na ordem indicada.
5. Use `05-agent-command.md` como comando inicial para o agente implementador.

## Princípio central

> Cada residência nasce da terra.

O protótipo deve ser uma experiência arquitetônica contínua e explorável. Não deve parecer catálogo, apresentação de slides, formulário ou passo a passo.
